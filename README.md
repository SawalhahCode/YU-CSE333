# YU-CSE333
Yarmouk University PBL for Course CSE333 - Data and Software Security

API Security Testing Workbench (Student Grades Portal API)

This is a repo that is for the project thats for the course CSE333 in yarmouk university, its is a built lab, to test some of OWASP API known flaws and its mitigations.

Warning: Some snapshots of this project is intentionally vulnerable, for learning only, don't deploy.

The milestones documents are in milestones/ directory, you can check the official submissions for this project.
